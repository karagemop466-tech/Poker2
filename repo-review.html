Repo review

Line-by-line state of the repository as of 2026-11-19, after the integration pass.

Structure

  • data/master.json — unified dataset (events, hotels, rate logs, rules, flags) generated by scripts/build_master.py from verified inputs.
  • data/session-updates.json — this session’s official-source reads (structure-sheet excerpts, recurring venue feeds, hotel facts).
  • data/source_monitor.json — URL/hash registry maintained by scripts/monitor.py (scheduled).
  • Root pages (this dashboard) — generated by scripts/build_site.py; row-level source check fails the build if a row lacks an official link.
  • docs/ and verified/ — earlier session dashboards, preserved as archives and linked in the footer.
  • COORDINATION.md — shared task board for parallel sessions.

Irregularities found in earlier data (flagged, not silently fixed)

  • Three overlapping dashboards exist (root, /docs/, /verified/). This root dashboard supersedes them; consolidation is suggestion S-C.
  • Earlier datasets disagreed on chip counts and reg-close times for some Venetian rows (see session arena/acd81e67-poker2 notes in COORDINATION.md). Rows in this site use the structure-sheet values where the sheet was read; others carry blanks.
  • “Verified single-entry” in older files meant “no re-entry language found”. This site labels that state precisely (“Sheet silent on re-entry — sheet read”) and states in every legend that silence is not a published freezeout rule.
  • Wynn WPT “NIH” naming, the Venetian series-label staleness, and the Caesars guide-vs-flyer buy-in conflict are preserved as flags.

Verification performed in this integration pass

  • 13 Venetian structure PDFs read directly (structures 8, 17, 18, 22, 23, 26, 27, 28, 29, 30, 31, 32, 33) + multi-flight sheets 2 and 9.
  • Wynn poker page, Caesars poker guide, MGM Grand poker page, Golden Nugget daily page re-read directly.
  • Hotel facts: Venetian tax/resort-fee/player-rate pages and Wynn resort-information page are the basis of every hotel value; Caesars fees intentionally blank.
  • Build-time check: every event and hotel row must cite an official https source or the build fails.
