02 / START-TIME PLAN

The earliest recurring official start found is 9:00 AM at Horseshoe. That listing does not include buy-ins or entry rules. A start time is not a promise that one event will finish before another begins.

Do not chain events by start time alone. Registration cutoffs, event duration, and late-registration terms vary. No finish-time estimate or back-to-back itinerary is represented as verified.

04 / OPEN DECISIONS

What is needed to make this bookable

01
Strict single-entry classification

An event is promoted only when an official structure or registration rule explicitly establishes the entry limit. A one-day label, a missing re-entry clause, or a single displayed buy-in is not proof. Unknowns stay flagged; confirmed re-entry, rebuy, add-on, and multi-flight formats stay separate.
