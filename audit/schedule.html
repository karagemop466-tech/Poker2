Day plan

One primary event per day, earliest start first, and a second event only where the player can realistically still enter it. The test is not the start time: it is the late-registration close of the second event versus when the first event can plausibly be left. A timetable that assumes a 5 PM finish is wrong most days.

There is no 8 AM event. The earliest row on the whole series is 09:10 (a turbo satellite) and the earliest one-day event is 10:10. A full day that begins at 8 AM cannot be built from this venue's published schedule — see FD-11.
