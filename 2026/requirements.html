Every requirement, and where it stands

The brief behind this project is a list of specific requirements. This page takes each one in turn and shows the page that answers it, what was actually checked against an official document on 2026-11-19, and what is still missing. Nothing here is marked met on the strength of a page existing.

16 met, 9 partial, 1 blocked, out of 26 requirements. A requirement is partial when the page works but the official evidence behind part of it has not been published, and blocked when no official source read publishes what it needs. The one blocked item is the 8 a.m. all-day start, because the earliest published start in the series is 9:10 AM. Nothing on this page is a booking recommendation; see latest evidence.

How to read the status

  • BLOCKED No official source read publishes what this requirement needs. Right now that is the 8 a.m. all-day start.
  • MET The page exists and this session checked the evidence behind it on 2026-11-19.
  • PARTIAL The page exists, but official evidence for part of the requirement is still missing.

The requirements that are not met, in one place

  • The 8 a.m. start (R-10). Earliest published start in the whole series is 9:10 AM on 2026-12-12; main-schedule events start at 10:10 AM or later. See N-06.
  • Confirmed single-entry events (R-02). Zero of 64 audited events has a written whole-event one-entry clause. See F-01.
  • True cost per night (R-05, R-06, R-07). No dated room rate or itemised checkout total could be captured; the booking engines return a loading shell. Blanks are unverified, not zero.
  • Certified walk times (R-18). The matrix is a routing estimate; none of it times the indoor route to a poker room.
  • Playable sequences (R-09, R-17). No official sheet publishes a finish time, so no two-event sequence is certified as playable.

Data policy. Every value on this site is transcribed from an official venue document that was read and is linked on every row. A value the organiser does not publish is left empty and listed on Flagged for review. Routing and cost estimates are labeled separately. Core structure-sheet audit: 2026-11-17.
