What this room publishes

Poker room: Wynn Poker Room (WPT World Championship host room). Host room for the WPT World Championship (Nov 27 - Dec 21) and the daily slate. Its page states the Friday daily is a '$40,000 guaranteed NLH Rebuy' and prints no buy-in or entry limit for any daily event, so no Wynn event can enter the single-entry table.

Checked 2026-11-17: Read first-hand on 2026-11-17 at https://www.wynnlasvegas.com/casino/poker. The room publishes three tournament documents - WPT World Championship (Nov 27 - Dec 21), the Wynn Signature Series (January 11-24, 2027) and a daily-tournament poster - and the page states the daily slate runs 'twice a day during non-event timeframes' with '$200,000 in guaranteed prize pools weekly'. No start time is printed on the page except the evening event ('a $10,000 guaranteed event every evening at 6 p.m.'), and no buy-in is printed for any daily event. The older URL this site used to cite, /casino/poker-room, returns Wynn's not-found page and is the reason the scheduled re-check logged HTTP 404 for this venue.

Wynn's official WPT World Championship structures PDF prints 'Unlimited re-entry until the start of level 9' for the $600 Turbo, the $600 mixed-game events, and the $400 / $1,100 PLO events.
cdn.wynnresorts.com, retrieved 2026-11-16
The same PDF prints the buy-in splits, e.g. $600 NLH $400K GTD is $510 prize pool + $65 house fee + $25 staff gratuity.
cdn.wynnresorts.com, retrieved 2026-11-16

Verdict: Excluded from the single-entry ranking. Two independent official statements support the exclusion: the WPT structures PDF prints unlimited re-entry on named events, and the room's own page advertises the Friday daily as a '$40,000 guaranteed NLH Rebuy' - a rebuy is a second buy-in, so the event cannot enter a single-entry table on either reading.
