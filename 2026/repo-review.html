Repo review, line by line

What the repository contains today, what this session changed, and what is still lying around from earlier sessions.

What this session did

  1. Read the coordination board. Every prior task is marked done; no other session holds an active claim.
  2. Read all 37 official Venetian structure sheets, one by one, covering all 64 event numbers. This closes the gap that several earlier sessions logged as open (FG-03 / S-02: 27 sheets unread).
  3. Read the official schedule from both the HTML event page and the schedule PDF, and reconciled them row by row. The PDF prints registration closes, chip counts and level lengths the HTML page does not. Found irregularity X-01.
  4. Re-read the official poker-room page, resort-fee page and poker suite-rate page.
  5. Checked seven other poker rooms and recorded what each publishes.
  6. Rebuilt the site from that data.

The site root is a separate, live surface

The repository root serves an older multi-venue dashboard that another session is still maintaining and regenerating from its own dataset (data/master.json) with its own generator (scripts/build_site.py). It is not legacy: it is simply a different surface with a different generator. This site lives under /2026/ so the two never overwrite each other, and every page here links back to the root. Nothing in /2026/ is derived from the root dashboard, and nothing on the root was edited to make this site.

Irregularities found in the repository

  • Three overlapping scheduled monitor jobs — recheck.yml, source-monitor.yml and the plan-*.yml jobs all re-check the same official URLs on different cron schedules. S-10
  • Three overlapping generators for superseded surfaces — scripts/build.py, scripts/build_site.py and scripts/build-site.py. Only build2026.py writes the live pages.
  • Stale claims on the board. Earlier records say “no Venetian sheet prints a re-entry clause.” That is now known to be wrong for sheet 8, which prices subsequent buy-ins, and incomplete for the multi-flight sheets, which print a flight rule. Per-sheet silence is not series-wide silence.
  • The “earliest verified start” claim. Earlier records say 10:10 AM. That is right for main-schedule events, but satellite event 46 starts at 9:10 AM. Neither is 8 AM.

Data policy. Every value on this site is transcribed from an official venue document that was read and is linked on every row. A value the organiser does not publish is left empty and listed on Flagged for review. Calculations and routing estimates are labelled separately from verified facts. Core sheet retrieval: 2026-11-17; later reads carry individual dates.

This is a research tool, not a booking service. Re-confirm every official page before you pay anything non-refundable. This /2026/ surface is generated by scripts/build2026.py; the site root hosts the older multi-venue dashboard, and the two do not share a generator.
