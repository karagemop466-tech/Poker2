Scheduled re-check

A GitHub Actions job (.github/workflows/recheck.yml) re-fetches every official URL on this page each Las Vegas morning, fingerprints the source, and appends the run to data/verified2026/checks.json. A changed hash is reported rather than guessed at — the Tournaments table then marks that row's Source re-check cell as source changed so you know which cited value may have moved. 83 URLs are registered for monitoring, including all 37 structure-sheet URLs. The latest run below fetched 63 of them: 20 were added to the register after that run and will be baselined by the next one. A fetch error means the job could not read the document — often a bot wall (HTTP 403) or a 302 redirect on a property that restricts scripts — and it proves nothing either way; those rows keep their previous hash and their old read date.
