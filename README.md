# Vegas Poker Planner

A conservative, source-linked Las Vegas poker trip planning dashboard. It currently publishes an official-source-checked selection of Venetian DeepStack Extravaganza IV events, separates formats needing additional review, and explicitly leaves unverified tournament rules and hotel costs blank.

## View locally
Open `index.html` in a browser. This is a static site and requires no build step.

## Publish with GitHub Pages
The repository's GitHub Pages deployment can serve the root `index.html` directly. Enable Pages in repository Settings → Pages, selecting the deployment workflow after the workflow is added or the `main` branch root. This session cannot truthfully claim Pages is live until a deployment is configured and succeeds.

## Research caveats
- Source: [Official Venetian tournament schedule](https://www.venetianlasvegas.com/resort/casino/poker/deepstack-extravaganza-poker-tournament/dse-nov-2026.html), checked November 16, 2026.
- A calendar listing is not sufficient evidence of single-entry or no-rebuy/add-on rules. Unknown formats are not treated as qualifying.
- Exact lodging totals need dates, occupancy, and an official booking quote; blanks are intentional.
- See the site's **Flagged for review** section and `COORDINATION.md` for verification limits and follow-up work.
