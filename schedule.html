DAY BY DAY

One primary event per day,
one conditional fallback.

Built from official start times, official late-registration close times and the official level structure. Because no organiser publishes an expected finish time, a second event on the same day is always conditional, never a plan.

The planner

Primary = a one-day event that starts before 3:00 PM, so the day is used from the morning; among those, the largest advertised guarantee wins and ties break earlier. If a date has no daytime one-day event, the primary becomes the largest-guarantee event of any start time and the row says so — presenting an evening-only day as a full day would be misleading. Multi-flight, satellite, restricted and restart events are excluded from the primary slot because they cannot be freely swapped once a flight has been played. Fallback = a later one-day event whose late-registration close still leaves a realistic chance of entering after a bust, so it is usable if the primary sells out at the cage.
