Hotels — true cost per night

True cost/night = (room rate + mandatory resort fee) × (1 + tax) + parking. The 13.38% room tax is the Clark County transient lodging rate: the county’s own licensing guide for hotel/motel establishments prints 13.38%, the county’s combined transient lodging return breaks it into an 8.5% and a 4.5% county component, and both The Venetian’s and The Cosmopolitan’s hotel terms state 13.38% verbatim. County guide (PDF) · county tax return components (PDF). Rates are kept as a dated log, never a single value.
