How to read this

  • Changed: response SHA-256 differs from the previous successful check. Re-open the linked official source, compare the relevant row, and update researched data only after confirming the exact value.
  • Unavailable: HTTP/network/fetch-limit failure. The prior successful hash is retained; this is not treated as a source change.
  • Baseline: first successful fetch. No prior hash existed, so no change conclusion is possible until a later successful check.
  • Unchanged: response hash matches the prior successful fetch.

The first scheduled run establishes baselines; external sites can block automated fetches or return temporary errors. The scheduled run is at 07:00 UTC daily, subject to GitHub Actions queue delays. Source-check freshness is not the same as re-verifying every value in each event row.

Every monitored URL originates in the official-source registry. Changes are review flags, never silently accepted tournament facts.
