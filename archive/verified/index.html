How to use this site

  1. Start with Single-entry. Rows are ranked by guarantee divided by buy-in (computed from official figures).
  2. Check Excluded for events with re-entry, rebuys, add-ons or extra flights. They are kept out of the ranking.
  3. Use Venetian schedule to plan a day. Start times are official; event length is not verified.
  4. Answer the open items on Questions before booking. Review Flagged for Review for irregularities.

Every table row links to an official source. Values that could not be confirmed from an official source are left blank and marked UNVERIFIED. Not a betting or financial product. Confirm with the venue before paying.
