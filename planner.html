Trip planner

Estimated cost of a trip = entries × buy-ins + nights × true hotel cost, where true hotel cost/night = (rate + resort fee) × (1 + tax) + parking. Enter values only from verified rows or your own dated quote.

Decision workflow — do these in order

  1. Fix trip dates and a nightly budget / quality floor first. Every later comparison is meaningless until the stay is fixed; hotel quotes are date-specific and quality is unrated by official sources, so the floor is yours to set.
  2. For each candidate event, get the official structure sheet and the written entry rules. Remove any event that does not match the single-entry policy (no re-entry, no rebuy, no add-on, no second buy-in). Today no room publishes that rule — so the removal test is instead: drop every event whose sheet prices a second buy-in, runs multiple flights, pays bounties, or awards seats.
  3. Compare only the survivors on guaranteed pool, total entry fee, starting stack and blind duration, payout structure, and daily schedule fit. Rank by guarantee ÷ entry fee only after the fee and guarantee are both confirmed — and read it as a descriptive ratio, not a forecast.
  4. Obtain itemized hotel totals for the same stay (checkout total, nightly average, resort fee, tax, parking, cancellation deadline, rate timestamp) and check the walking route is under 30 minutes from each hotel to the venue.
  5. Build one event per day first. Add an evening event only where you can realistically exit the earlier one — no organiser publishes a finish time, so a second event is always a conditional fallback, never a plan.
  6. Reconfirm official schedules, rates, and policies before any nonrefundable payment. Every row carries a last-checked date and a source link; re-open it the day you pay.

Day-by-day plan — primary + conditional fallback

No casino publishes finish times, so this plan uses only two published facts: each event's start time and the clock time its structure sheet prints for the close of registration. Nothing here assumes how long you will last. The primary event is the earliest event that is actually enterable on that date; the fallback is a later event on the same date whose printed registration close falls after the primary's start, so it is still open if you are eliminated early. A row is flagged only when the documents make the pair impossible — either the fallback's registration had already closed before the primary began, or two events at different properties start within 30 minutes of each other.
