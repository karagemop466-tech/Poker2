The decision path, and where each step is answered

The order below is the order a booking has to happen in. Each step links the page that carries its evidence; a step whose answer is not on the site is a gap, not a permission to assume.

  1. Fix the dates, the nightly budget and the quality floor. Nothing downstream can be compared until the window is set — trip planner holds the window and the floor.
  2. Get the official structure sheet for each candidate event, with its written maximum-entry / no-rebuy / no-add-on rule. The per-field readings and what each sheet actually says live on entry rules; events that do not match a single-entry policy are separated on the tournament table and on the spend-more pages.
  3. Compare only the surviving events on guarantee, buy-in, stack and blind length, payout structure and schedule fit — ranking (ratio of published guarantee to published entry fee; descriptive, not a forecast).
  4. Price the same stay at each hotel, and check the walk — hotels for fee, tax, parking and the dated rate log, walking times for the 30-minute test.
  5. One event per day first; an evening event is added only where the player can really leave the earlier one — day plan and schedule.
  6. Re-confirm the official schedule, rate and policy before anything non-refundable — source monitor records when each cited document was last re-read, and flagged for review lists what is still unproven.

How to read this site

  • Sheet silent on re-entry — the official structure sheet was read in full and prints no re-entry, rebuy or add-on mechanism. It also never states “no re-entry”: this is silence, not a published freezeout rule, so no event on this site is labelled confirmed single-entry (see flag IR-8234-02).
  • Entry limit ambiguous — sheet read, but wording suggests possible extra buy-ins.
  • Spend-more — a verified way to buy more chips or entries. Kept out of the main ranking.
  • UNVERIFIED — the value or rule could not be confirmed from an official source. Left blank, never inferred.

Pool ÷ fee figures are descriptive ratios of published numbers only, not forecasts of value or ROI.

Quick tools

  • Trip cost calculator — entries × buy-ins + nights × true hotel cost.
  • Day-by-day plan — primary event + conditional fallback per day, overlap flags.
  • True hotel cost/night — room rate + resort fee + tax, logged as dated entries.
  • Source monitor — scheduled re-checks of every official URL; changed sources are flagged.
  • Descriptive ranking — guarantee ÷ total entry fee, bounty/flight events labeled separately.
