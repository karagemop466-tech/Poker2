When you have an itemised quote, append a row with arrival_date · departure_date · nights · occupancy · room type · rate plan · nightly rate · resort fee · taxes · total at checkout · cancellation deadline · page URL · date and time captured — the calculator then uses it instead of a “from” rate.
Which engines can be read without a browser: The Venetian's own booking engine (venetianlasvegas.com/booking?...&view=calendar) renders a complete itemised breakdown in its HTML, so dated quotes for The Venetian / The Palazzo are capturable and are logged below as of 2026-11-17. Wynn (wynnlasvegas.com/book) and the MGM property sites return an empty shell or a 404 for every dated URL tried on 2026-11-17 - their prices are built by XHR after load - so no quote is claimed for them. Quotes also fail to render for some date ranges even at the Venetian (a Dec 9-12 and a Dec 9-16 request both returned the calendar with no rate block), so a failed render is recorded as no quote, never as a price.
