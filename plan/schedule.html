Day plan — one primary event, one conditional fallback

Built only from rows whose fee and guarantee are confirmed. Each day gets one primary — the highest published guarantee-per-entry that starts before noon, so the day is actually long — and, where one exists, an evening event that is usable only as a fallback because its registration is still open when you would bust out.

The 8 AM question. The earliest start published anywhere in the series is 9:10 AM (a Dec 12 satellite) and the earliest cash-prize start is 10:10 AM. A day cannot be planned earlier than the schedule, so each day starts as early as the series does; the 10:10 AM RaceDay format is the only verified second-shot option.
  1. Primary events are drawn only from rows whose official structure sheet was read and whose fee and guarantee are both confirmed.
  2. A primary must be open to all players: rows whose sheet restricts entry (50+, female-only, tag-team) are listed with the restriction, never scheduled as the primary.
  3. Highest published guarantee-to-buy-in size ratio that starts before 12:00 is the day's primary.
  4. An evening event is shown only as a conditional fallback, and only when its late-registration cutoff is later than the primary's.
  5. Overlap is flagged when the later event starts at or before the earlier event's earliest plausible finish (registration close + one level).
  6. Night-eligibility uses the official poker-rate condition: $300+ tournament buy-in or six hours of live cash per night.
  7. Finish times are not published anywhere: the 'earliest plausible finish' column is a derived clock value, not a schedule.
